Defect IDs now identify their use case, with numbering starting at 001 within each use case (for example, UC-002-BUG-001). SETUP-BUG-001 covers installation outside the product use cases. The documentation gap is not counted among the seven application defects. The older decks are retained as historical references and still show the earlier short IDs.

The recorded run has 18 cases: 8 passed, 9 failed and 1 blocked. Application source was not changed. These are results from 18 September 2026, not a claim about later revisions.
